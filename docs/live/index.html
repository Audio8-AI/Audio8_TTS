Audio8-TTS-0.6B

Live text-to-speech synthesis, running entirely in your browser via ONNX Runtime Web. Nothing is uploaded to a server.

Listening samples GitHub

1. Load the model

Downloads about 572 MiB on first visit, then caches locally in your browser for repeat visits (Cache Storage API). Requires WebAssembly.

WebGPU currently fails at inference time for this model due to an upstream onnxruntime-web WebGPU shape-handling bug in the MatMulNBits (INT4) kernel, reproduced on the latest nightly build as of 2026-08-23. Use WASM until that is fixed upstream.

Idle.

2. Optional: clone a reference voice

Upload a 0.5-30 second clean recording and its exact transcript. If skipped, a built-in placeholder reference is used.
